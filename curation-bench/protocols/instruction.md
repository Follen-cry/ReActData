# Instruction-Guided Research Appendix

The preceding method protocol remains binding. This optional mode follows upstream's
prescriptive research workflow, adapted to video supervision rather than VQA.

For each improvement, write curation/research.md before editing the construction
program. Include: observed dev failure modes, per-item evidence, a falsifiable
hypothesis, one minimal intervention, expected effect and a stopping criterion.
Summarize the same hypothesis in curation/hypothesis.md for submission. After dev,
record the outcome, failure mode and next research question in NOTES.md. Separate
observations from speculation; retain negative results and uncertainty. Accepted
code snapshots include research.md automatically.
